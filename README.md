# Зачем это нужно
Скрипт инсталлятор которой автоматизирует рутинную установку и настройку необходимых программ. Инсталятор проверяет хост систему на которой запущен, после чего начинает устанавливать пакеты, создавать симлинки конфигов в домашней дирректории. Список программ и симлинков зависит от системы. Инталятор был написан под решение потребностей автора.

# Что инталлятор делает
Сначало инталятор проверяет на каком дистрибутиве был установлен, если дистрибутив поддерживается то интсаллятор обновляет систему и устанавливает массив базовых пакетов. Если текущим дистрибутивом является Arch тогда к массиву с базовыми пакетами докасиваются также **графический сервер niri и консоль foot**. После установки пакетов, инсталлятор создает симлинки конфигурационных файлов, шрифтов по всей домашней дирректории используя программу **stow**.

# Установка
При клонировании репозитория инсталлятора, достаточно иметь установленным `git` на своем дистрибутиве.

При установке программы через `curl` помимо curl также потребуется `unzip` для расспаковки установленного инсталлятора.

# Поддерживаемые дистрибутивы
## Arch linux
```zsh
curl -fsSL https://github.com/nerdinhisprime/.dotfiles/archive/refs/heads/main.zip -o /tmp/dotfiles.zip && unzip -q /tmp/dotfiles.zip -d /tmp && rm -rf ~/.dotfiles && mv /tmp/.dotfiles-main ~/.dotfiles && rm /tmp/dotfiles.zip && cd ~/.dotfiles && chmod +x install.sh && ./install.sh
```

## Termux
``` zsh
curl -fsSL https://github.com/nerdinhisprime/.dotfiles/archive/refs/heads/main.zip -o $TMPDIR/dotfiles.zip && unzip $TMPDIR/dotfiles.zip -d ~ && mv ~/.dotfiles-main ~/.dotfiles && rm $TMPDIR/dotfiles.zip && cd ~/.dotfiles && chmod +x install.sh && ./install.sh
```
